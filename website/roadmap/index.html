Roadmap

What comes next.

This is a direction, not a promise. Zinely stays small: an idea moves forward only when it solves a real problem without weakening saved work, print correctness, accessibility, or the offline experience.

Last reviewed: 9 September 2026

Planned

Finish the public-beta path

  • Keep the signed beta download, privacy information, backup guidance, and support path current.
  • Complete store publication when the owner’s account-verification requirements can be satisfied.
  • Continue focused fixes only when device or tester evidence shows a real problem.

Exploring

Useful improvements, not commitments

  • Optional folding animations in the app, if testing shows they make the instructions easier to follow.
  • Safe cleanup of unused imported images, but only with import pinning and recovery tests.
  • Shelf search or organization if a larger real library proves the need.
  • A small, licensed font set only after editor, preview, raster, PDF, and print parity.

Not committed

Ideas kept outside the current product

  • New zine formats, freehand drawing, and a much larger Art catalogue.
  • Cloud accounts, feeds, social features, or automatic online processing.
  • Direct in-app printing until fixed-scale output can be proven across real printer paths.

The detailed engineering sequence remains in the repository’s canonical roadmap.
