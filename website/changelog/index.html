What changed.

A short, human-readable history of public releases and earlier tester builds that affect people using Zinely. Newest entries appear first.

Public beta release

Published 9 September 2026

0.9.0-beta.4-r3

Readable dark-mode confirmations

  • Fixed the low-contrast “Duplicated” confirmation and Undo action in dark mode.
  • Kept the message wording, timing, placement, and light-mode appearance unchanged.

Tester build

Built 31 August 2026

0.9.0-beta.4-r2

A smaller download

  • Reduced the release package using Android’s release-only code and resource shrinking.
  • Changed the generated launcher artwork from PNG to lossless WebP without changing its pixels.

Tester build

Built 31 August 2026

0.9.0-beta.4

Replace a photo without rebuilding the page

  • Added Replace Photo through Android’s existing photo picker.
  • Preserved position, crop, framing, effects, and undo history while changing only the photo source.
  • Made Photo and Art replacement routes unambiguous for screen readers.

Tester build

Built 30 August 2026

0.9.0-beta.3

A clearer, more dependable editor

  • Added whole-library backup and recovery, persistent deletion, Flip, Reframe, and duplicate-page improvements.
  • Improved large-text, TalkBack, dark-mode, page-navigation, and autosave behavior.
  • Reduced the first Add-to-Art transition frame work while preserving one stable shared sheet.
