# Zinely 0.9.0-beta.4-r1 - tester package

## Zinely - beta 4 maintenance revision

This is an up-to-date maintenance build of beta.4. It adds no new product behavior: Replace Photo,
the shared Add/Art sheet, backup/recovery, rendering, accessibility, and saved-document behavior are
the same as beta.4. The higher Android `versionCode` makes this APK a valid update while the original
beta.4 package remains preserved separately.

## Before installing

This APK is signed with the same Zinely release key as beta.1-beta.4, so Android can install it as an
update without deleting your zines. **Do not uninstall the existing app.** Making a fresh backup from
**Backups** before any beta update is still sensible.

1. Download `zinely-0.9.0-beta.4-r1-release.apk` to the phone.
2. Tap the file. If Android asks whether the app that opened it may install unknown apps, allow that app
   and return to the installer.
3. Choose **Update** / **Install**, then open Zinely normally.

Zinely needs Android 7.0 or newer. It has no account, analytics, cloud sync, or network permission; your
zines stay on the device unless you deliberately export or share a file.

## What to try

This revision intentionally changes no workflow. A focused smoke pass should confirm:

1. An existing zine opens and keeps its pages, photos, text, and Art.
2. Replace Photo still preserves the frame and supports one-step Undo/Redo.
3. Art Replace still opens the Art cabinet rather than the photo picker.
4. Backup/recovery remains reachable.
5. Read, Save PDF, Open PDF, and Print & fold remain reachable.

Please send feedback through the same channel that brought you this APK. The most useful report says what
you were doing, what you expected, what happened instead, and your phone/Android version.

## Known limitations

- Android owns the photo picker. On some phones a selected image goes through an extra **Preview** /
  **Done** step before returning to Zinely.
- Replaced and deleted photo assets are not reclaimed yet, because another element or zine may share the
  same content-addressed file. App storage can therefore grow over time.
- Font choice is still unavailable. Unsupported scripts are kept and warned about but do not print yet.
- Zinely saves the PDF; printing happens in the phone's PDF or print app.
- The public privacy-policy page remains a separate publication gate awaiting owner-provided details.

## Verification

- The full Gradle test suite and pinned golden workflow passed without changing golden files.
- `:app:lintDebug`, `:app:assembleDebug`, and release-signed `:app:assembleRelease` passed.
- A second release build reported `packageRelease` and `assembleRelease` as `UP-TO-DATE`, tying the copied
  APK to the committed release-prep source.

  `0.9.0-beta.4-r1`, minSdk 24, targetSdk 36, and no Internet permission.
- Signature inspection confirmed APK Signature Scheme v2 and the same release certificate as the frozen
  beta.4 APK.
- An isolated Android 16 emulator accepted both a clean installation and an in-place update from the
  frozen beta.4 APK. `firstInstallTime` remained `2026-08-31 15:54:09`, `lastUpdateTime` advanced to
  `2026-08-31 15:55:46`, and the upgraded app launched via `MainActivity`.
