# Zinely 0.9.0-beta.4-r3 - tester package

## Zinely - readable dark-mode confirmations

This focused beta.4 maintenance update fixes the editor confirmation message in dark mode. Messages
such as **Duplicated**, together with their **Undo** action, now use readable high-contrast colors.
Saved zines, backups, document format, rendering, export, and every editor command remain unchanged.

## Before installing

This APK uses the same Zinely release key as beta.1 through beta.4-r2, so Android can update an existing
release-signed beta without deleting its data. **Do not uninstall the existing app.** Make a fresh backup
from **Backups** before any beta update.

1. Download `zinely-0.9.0-beta.4-r3-release.apk` to the phone.
2. Tap it, allow that file-opening app to install unknown apps if Android asks, then return to the installer.
3. Choose **Update** / **Install**, then open Zinely normally.

Zinely requires Android 7.0 or newer. It has no account, analytics, cloud sync, or network permission.

## What to verify

1. Existing zines and backups remain reachable after updating.
2. In dark mode, duplicate a Photo, Text, or Art element and confirm **Duplicated** and **Undo** are easy to read.
3. Tap **Undo** and confirm the duplication is reversed as one history step.
4. At large text (up to 1.8x), confirm the notification and action remain readable and reachable.
5. Add, Replace, Reframe, Flip, Delete, Read, Save PDF, and Print & fold remain unchanged.

## Known limitations

- Android owns the photo picker and may show an additional Preview / Done step.
- Replaced and deleted photo assets are retained, so app storage can grow over time.
- Font choice remains unavailable. Unsupported print scripts are kept and warned about but do not print.
- Zinely saves the PDF; printing happens in the phone's PDF or print app.
- Privacy-policy publication remains blocked on owner-provided details.
