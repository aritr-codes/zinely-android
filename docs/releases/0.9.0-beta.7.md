# Zinely 0.9.0-beta.7 - tester package

> **Status: released 2026-10-11.** Tag `v0.9.0-beta.7` on merge `95d64ae`; GitHub pre-release, APK only.

## Zinely - folders, and a second font

This update adds two things you can see. On the Shelf, a zine can go in a **folder**: from its three dots,
*Move to a folder*; a folder shows as a pile of its zines' covers. On the Bench, a text can be set in **Book**,
a serif font with its own bold and italic, beside **Plain**, the font every zine has used so far: select the
text, tap **Text**, and the card's first row is Font. The button that opens that card was named "Size". Two
fixes come with it: a zine restored straight after being deleted now shows and stays, and a longer text no
longer moves when you tap Done. The full list is in the
[changelog](../../CHANGELOG.md#090-beta7--2026-10-11--folders-and-a-second-font).
Saved zines open as before, and the document format is unchanged.

Folders and the second font ship **built and merged, not yet accepted**: what is still owed is under
[Not verified](#not-verified).

## Before installing

This APK uses the same Zinely release key as beta.1 through beta.6, so Android can update an existing
release-signed beta without deleting its data. **Do not uninstall the existing app.** Make a fresh backup
from **Backups** before any beta update.

1. Download `zinely-0.9.0-beta.7-release.apk` to the phone.
2. Tap it, allow that file-opening app to install unknown apps if Android asks, then return to the installer.
3. Choose **Update** / **Install**, then open Zinely normally.

### If you have Zinely 0.8.0 or older

Those builds use a different signing key, so Android cannot update them to this beta. Preserve anything
you care about **before** uninstalling the old app: in 0.8.0 use **Preview › → Print setup → Save PDF**;
in 0.6.0-alpha.1, which has no save action, share the zine somewhere durable. Only then uninstall the old
build and install this APK. Uninstalling the old build deletes its private library.

Zinely requires Android 7.0 or newer. It has no account, analytics, cloud sync, or network permission.

### If you might go back to an older version

A zine with **Book** text, opened or restored on 0.9.0-beta.6 or earlier, is drawn in Plain there. Every word
is kept, but lines break in other places and lines that no longer fit their box are missing from the page and
the PDF on the older version, which does not say so. An older version also restores a backup that has folders
with every zine on My Shelf.

## What to verify

1. Existing zines and backups remain reachable after updating.
2. On a zine's three dots, **Move to a folder**: make a folder, see it as a pile, open it, rename it, take its
   zines out. Moving and taking out offer Undo for a few seconds.
3. Select some words: the toolbar shows Edit, **Text**, Ink, Duplicate and Delete. Tap **Text**: the card's
   first row is **Font**, with Book and Plain.
4. Set a text to **Book**. Undo says "Font put back"; Redo says "Font changed".
5. Make a Plain text smaller than 12 pt and open the card: Book is shown as unavailable and the card says why.
6. Type four or more lines and tap **Done**: the lines stay where they were.
7. **Print one page with a Book text at 12 pt** and say whether it reads well. This is the one check nobody has
   done yet.
8. Add, Replace, Reframe, Flip, Across fold, Duplicate, Delete, Read, Save PDF, Share, Backups and Print & fold
   remain unchanged.

## Known limitations

The authoritative list is the changelog's
[Known limitations](../../CHANGELOG.md#090-beta7--2026-10-11--folders-and-a-second-font). In short: a text that
just fits its box can lose its last line when switched to Book, with no sign; Book's 12 pt minimum is not yet
confirmed on paper; older versions draw Book text in Plain and can drop lines, and restore folders as My
Shelf; folders and the Font row have not been checked by ear with TalkBack; **Text** and **Text style** open
the same card; and everything listed for beta.6 except "there is no font choice" still applies. Google Play
distribution is not available; this beta is distributed directly through GitHub as an APK.

### On device - this build

**Install over the existing app, this exact file.** On 2026-10-11 the owner said no backup was needed and to
proceed. `adb install -r` of the `dist/` APK, with no uninstall, was accepted over `versionCode 11` on the
owner's Samsung SM-A176B. `firstInstallTime` stayed `2026-08-31 18:19:22`; the installed file's SHA-256
matched the `dist/` APK; the app cold-launched in 316 ms and the Shelf opened headed "My Shelf" with 43
zines, the count recorded at beta.6. The crash buffer held nothing from the app. Nothing in the owner's
library was opened or changed.

**The smoke pass below did not use this file.** It ran earlier the same day, on **the same commit built the
same way** (the release variant, minified) under a separate package name, `com.aritr.zinely.voicesqa`, signed
with a debug key so the release key was not used for a test build. It sat beside the owner's app, used only a
made-up zine, and was removed afterwards with its test files.

**Smoke pass, Samsung SM-A176B, Android 16 (build `A176BXXS8CZI9`), 2026-10-11** (scripted taps at positions
taken from the platform accessibility tree; results read from the same tree):

- **First run and Shelf.** The app opened on the empty Shelf; a new A4 zine opened on the Bench.
- **Words and the bar.** Added words; the selected-text bar read Edit, Text, Ink, Duplicate, Delete, each a
  clickable, enabled button.
- **Font.** Text opened the card with Font first, Plain chosen. Tapping Book chose it, and the card then said
  "Book stops at 12 pt. Switch to Plain to go smaller." with Smaller marked unavailable. Undo showed "Font put
  back" and Plain; Redo showed "Font changed" and Book.
- **Save PDF.** "Saved to your phone"; the file in Downloads embeds `Fraunces9pt-Regular`. The file was
  deleted.
- **Folders.** From the zine's three dots, Move to a folder, name "Trips", Make folder: the Shelf showed
  "Trips, folder, 1 zine". Opening it showed the zine inside.
- **After a cold start** (force-stop, relaunch): the folder was still there, and the zine's text was still
  Book.
- **Backup, then restore of the same file.** "Backup saved. All 1 zine is together in one backup file." The
  Backups sheet then read "Last backup saved 11 Oct 2026" with the file's name. The file's manifest carries
  the folder name and its document carries the Book font. Restoring it said "Nothing new to add. The zine
  from this backup is already on your shelf." The file was deleted.
- The crash buffer held nothing from the test package.

Not covered by either check: opening or editing an existing zine after the update, a photo, Reframe, Across fold, Share, rename
and take-out of a folder, a second zine, dark versus light theme, larger text, TalkBack, and anything on
paper.

- `:feature:editor:lintDebug`, which CI does not run, was not run for this release. At beta.6 it reported
  three errors in two test files.
