# Zinely 0.9.0-beta.4-r2 - tester package

## Zinely - smaller beta 4 maintenance revision

This is a packaging-only update. Zinely's workflows, document format, offline behavior, rendering,
accessibility, and saved zines are unchanged from beta.4-r1. The APK is smaller because release-only
shrinking removes unreachable code/resources and the unchanged launcher collage is packaged as lossless WebP.

## Before installing

This APK uses the same Zinely release key as beta.1 through beta.4-r1, so Android can update an existing
release-signed beta without deleting its data. **Do not uninstall the existing app.** Make a fresh backup
from **Backups** before any beta update.

1. Download `zinely-0.9.0-beta.4-r2-release.apk` to the phone.
2. Tap it, allow that file-opening app to install unknown apps if Android asks, then return to the installer.
3. Choose **Update** / **Install**, then open Zinely normally.

Zinely requires Android 7.0 or newer. It has no account, analytics, cloud sync, or network permission.

## What to verify

1. Existing zines and backups remain reachable.
2. Add Photo, Replace Photo, and Art Replace open their expected destinations.
3. Text and emoji appear in the editor, PNG output, and PDF output.
4. Read, Save PDF, Open PDF, and Print & fold remain reachable.
5. The launcher icon and brief system splash retain the same collage and central Z.

## Known limitations

- Android owns the photo picker and may show an additional Preview / Done step.
- Replaced and deleted photo assets are retained, so app storage can grow over time.
- Font choice remains unavailable. Unsupported print scripts are kept and warned about but do not print.
- Zinely saves the PDF; printing happens in the phone's PDF or print app.
- Privacy-policy publication remains blocked on owner-provided details.
