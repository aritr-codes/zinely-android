Materials & the Maker's Cover

The interface stays quiet — so the creations carry the warmth. This is where the café's colour lives: in paper, ink, and the covers people make. A study, not a screen. Nothing frozen is reopened.

01

Paper stocks

A short, named set of stocks — the maker's first creative choice. Grain and fleck evoke paper; the cover is heavier than the pages, which is the single strongest “real little object” cue. No embossing, no skeuomorphism.

02

The riso signature — print the process, not a filter

Riso is separate translucent ink layers that physically overprint into a third hue — each layer with its own slight misregistration and grain. That independence is the anti-kitsch rule: a single global “riso filter” is the tell. Keep the soul (offset + grain), drop the damage (no smudges, no streaks). Colours stay muted so a home printer can actually make them.

Two inks, two drums — overlapping where they meet. Toggle a layer to see it is really two.

Pick two inks from §04 to re-drum this print. Because the art is coverage, not colour, the same motif takes any ink:

  • Soul: layer offset ≤ 2–3 mm, grain, overprint blend.
  • Not damage: never smudges, roller-marks, streaks.
  • Home-honest: muted inks, not neon — they print on any inkjet/laser.
03

Maker inks — where the café's colour lives

~15 muted riso spot inks in three bands, held in a content namespace separate from the interface. Click any ink to re-drum the print above and re-tint the collection below — proof that one asset × N inks = N looks. This is the colour the frozen chrome deliberately withholds.

04

The Maker's Cover — a recipe that makes a collection

The Penguin/Marber move: freeze the grid, vary the ingredients. Each cover = { title × ink × mark × paper × motif } on one fixed layout. Every cover looks unmistakably Zinely and unmistakably theirs — a row reads as a collection, not a list. (Extends the frozen Library cover; honours ADR-069, no per-edit render.)

The Starter Creative Pack

So the first zine feels made, not configured — generous but scannable (one glanceable row per category), good defaults over a big library. All CC0 / OFL, tintable, print-and-sell-safe; notices live in-app, the exported zine stays clean.

The twee line — the whole guardrail

Texture reads warm when it is a believable consequence of a process — ink soaking paper, layers drifting, a heavier cover. It reads kitsch when imperfection is pasted on as decoration — deckle edges, coffee rings, faux-handwriting, random tilt, a uniform “vintage” filter. Restraint + physical plausibility is the line, and it holds across every material above.
